## 📌 Overview

**AI-Powered Species Distribution Modeler** is an open-source web application designed for biogeographical and ecological research. Built with Streamlit and Scikit-Learn, this tool bridges the gap between complex geospatial data processing and user-friendly analytics, enabling researchers and conservation planners to easily analyze and visualize species distribution data.

**Key Features:**
- 🎨 **Auto Dark Mode** - Interface adapts to system light/dark preferences
- 🌐 **Bilingual Support** - English and Vietnamese
- 📊 **Publication-Ready Visualizations** - High-quality plots ready for reports
- ⚡ **End-to-End Automation** - From data acquisition to result export with minimal clicks
